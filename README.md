# Portfolio

A high-impact data science portfolio website built with interactive visual storytelling.

## Features
* **Interactive Gateway:** Full-screen 2D map with city-based routing nodes.
* **Skill Network:** D3.js force-directed graph for technical tooling.
* **Dark Theme:** Ink and sunset color palette with a command-line look.

## Tech Stack
* HTML5, Tailwind CSS, JavaScript (Canvas & D3.js)
* Cloudflare Pages & GitHub
